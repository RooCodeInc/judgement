# Judgement for coding agents

Use the [Judgement skill](../skills/judgement/SKILL.md) to turn recurring user
corrections into scoped repository rules and labeled examples.

The [agent guide](../skills/judgement/references/agent-guide.md) covers schemas,
commands, calibration, and interpreting results. These files are included in the
npm package and can be read directly without installing the skill.

See the [README](../README.md#agent-skill) for skill installation.
